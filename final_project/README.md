# B.Tech and Degree Roadmaps

A simple student project made using HTML, CSS and JavaScript.

## Project files

- `index.html` - main page
- `css/style.css` - page design and styles
- `js/data.js` - roadmap and quiz data
- `js/app.js` - buttons, quiz, progress and login logic

## How to run

1. Open this folder in VS Code.
2. Install the **Live Server** extension if it is not already installed.
3. Open `index.html`.
4. Right-click the file and choose **Open with Live Server**.

The project works in the browser and saves the login name and roadmap progress using `localStorage`.
